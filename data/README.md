# Модуль Data

## Описание

Модуль Data отвечает за работу с базой данных и реализацию репозиториев для доменных сущностей.

## Структура

```
data/
├── src/
│   ├── main/
│   │   └── kotlin/com/inrotate/
│   │       ├── db/          # DAO и таблицы
│   │       └── repository/  # Реализации репозиториев
│   └── test/
│       └── kotlin/com/inrotate/
│           ├── db/          # Тесты для DAO
│           └── repository/  # Тесты для репозиториев
└── build.gradle.kts         # Конфигурация сборки
```

## Тестирование

Подробная информация о тестировании находится в файле [TESTING.md](TESTING.md).

## Запуск тестов

Для запуска тестов используйте команду:

```bash
./gradlew :data:test
```

или на Windows:

```cmd
gradlew.bat :data:test
```
